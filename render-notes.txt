# ============================================
# Render.com Deployment Configuration
# ============================================
# Деплоим 2 сервиса:
# 1. Frontend (Static Site - бесплатно)
# 2. Backend (Web Service - 750 часов/мес бесплатно)
#
# Telegram Bot запускается внутри бэкенда!
# ============================================

# --- Структура проекта ---
# platega/
# ├── backend/          → Web Service (Go + Telegram Bot)
# ├── frontend/         → Static Site (Next.js)
# └── render.yaml       → Эта конфигурация

# --- Бесплатные лимиты ---
# Static Site: ∞ трафик, ∞ времени
# Web Service: 512MB RAM, 750 часов/месяц
# БД: своя (PostgreSQL на ElephantSQL или PlanetScale)

# --- Как это работает ---
# 1. Frontend деплоится как Static Site на render.com
# 2. Backend деплоится как Web Service
# 3. Telegram Bot запускается вместе с бэкендом
# 4. База данных: используем бесплатный ElephantSQL

# --- Переменные окружения для Render ---
# FRONTEND:
# NEXT_PUBLIC_API_URL=https://your-backend.onrender.com
# NEXT_PUBLIC_WS_URL=wss://your-backend.onrender.com

# BACKEND:
# SERVER_PORT=8080
# DATABASE_URL=postgres://user:pass@ec2-xx-xx-xx-xx.compute-1.amazonaws.com:5432/dbname
# JWT_ACCESS_SECRET=<secret>
# JWT_REFRESH_SECRET=<secret>
# ENCRYPTION_KEY=<32 chars>
# TELEGRAM_BOT_TOKEN=<token>
# TELEGRAM_DISPUTE_CHAT_ID=<chat_id>

# --- Бесплатные базы данных ---
# 1. ElephantSQL: https://www.elephantsql.com/ (10MB бесплатно)
# 2. MongoDB Atlas: https://www.mongodb.com/cloud/atlas (512MB бесплатно)
# 3. Supabase: https://supabase.com/ (PostgreSQL, 500MB бесплатно)
